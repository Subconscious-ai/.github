# Agent instructions

## Finding the code

Issue authors choose a [form](.github/ISSUE_TEMPLATE/) on GitHub. Check the YAML field IDs and rendered prompts when changing intake. On a managed checkout, open the shared Repository tools guide for service ownership and runtime evidence.

## Agent skills

For specs, tickets, triage, implementation, or review, read:

- `docs/agents/issue-tracker.md`: GitHub Issues and repository delivery rules.
- `docs/agents/triage-labels.md`: mappings for the five triage roles.
- `docs/agents/domain.md`: existing domain sources and context layout.
